# Demo 5 — 因果倒置（中文）

此示例为合成数据，与任何真实研究、区域或机构无关。

## 失败模式

**因果方向倒置**：原文明确论证"接种率 → 重症率"（接种率是因，重症率是果），
并专门设计了一段反证段落驳斥反向因果。总结把因果方向**完全反转**为
"重症率 → 接种率"。两个语句的关键词高度重叠（"接种率""重症率""上升""下降"），
但因果箭头反了。

## 期望审计结果

| 总结中的论点 | 期望标签 | 原因 |
|---|---|---|
| "重症住院率与疫苗接种率之间存在显著的统计关联" | exact | 原文一致 |
| "因为重症住院率下降，所以接种率上升——重症率是因，接种率是果" | **reversed** | 原文明确说"接种率是因，重症率是果"，且专门反驳了反向因果 |
| "建议继续把社区健康宣教和基层动员作为主抓手" | exact | 原文政策建议一致 |

## 给真实审计器的挑战

因果倒置只翻转两个名词的位置，**否定词没有变化**——纯关键词重叠 + 否定词
对齐的启发式很可能给出 exact。这正是 mock backend 不可替代的语义判断需求点。
