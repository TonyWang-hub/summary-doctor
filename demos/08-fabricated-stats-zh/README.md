# Demo 8 — 数据纂改（中文）

此示例为合成数据，与任何真实项目、学校、地区无关。

## 失败模式

**数据纂改**：原文反复强调"没有给出具体百分比""理由是问卷信度尚未做正式
心理测量学验证""家长侧没有做量化打分""项目组建议在试验完成前不对外发布
任何具体的'提升幅度'数字"——也就是原文**主动拒绝**提供量化数字。总结却凭空
编造了 23% / 28% / 41% / 9.2 分四个具体数字，并把"相关性不能解读为因果"
的限制完全删除，直接给出"建议在全省推广"的结论。

## 期望审计结果

| 总结中的论点 | 期望标签 | 原因 |
|---|---|---|
| "课后辅导满一年的回访评估" | exact | 原文一致 |
| "作业自主完成率比对照组高出 23%" | **fabricated** | 原文明确说"没有给出具体百分比"，23% 完全编造 |
| "数学科目的差距达到 28%" | **fabricated** | 同上，原文只说"数学和英语两科上最为明显"，没有 28% |
| "学习意愿评分比对照组高出 41%" | **fabricated** | 原文明确说问卷信度未做心测验证、未公布数字 |
| "家长满意度问卷得分 9.2 分（满分 10 分）" | **fabricated** | 原文明确说家长侧以访谈为主、没有做量化打分 |
| "项目组认为效果显著，建议在全省推广" | **reversed** | 原文明确说"所有量化对比都只是相关性，不能解读为因果""建议下一阶段做小规模随机对照试验" |

## 为什么这个 demo 重要

数据纂改是 AI 总结最有害的失败模式之一：编造的数字读起来"专业"，给的人和
看的人都更容易当成事实接受。一个值得托付的审计器必须在 fabricated stats
这一类上有高召回——哪怕代价是 softened / scope-creep 上有一些漏报。

## 怎么跑

```bash
summary-doctor demos/08-fabricated-stats-zh/summary.txt \
  --original demos/08-fabricated-stats-zh/source.txt \
  --lang zh --mock
```
